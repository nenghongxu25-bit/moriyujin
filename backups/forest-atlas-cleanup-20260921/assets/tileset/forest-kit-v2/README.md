# 森林地形与独立元素 v2

本目录包含实际配置好的两套 TileSet，共 24 个地形块和 24 个透明装饰元素。

## 直接查看

在 LayaAir 打开 `forest-kit-demo.ls`，运行当前场景。
上半部分为实际 TileMapLayer 拼接的草地、泥土道路、水池和石地，并叠放独立元素；下方展示全部 24 个透明元素。
实际运行截图保存在 `docs/forest-kit-v2-runtime.png`。

## 文件与尺寸

| 文件 | 用途 |
| --- | --- |
| forest-terrain.png / forest-terrain.tres | 地形纹理和已配置的地形 TileSet |
| forest-props.png / forest-props.tres | 真正带 alpha 的独立装饰图集和 TileSet |
| forest-kit-demo.ls | 引擎内实际拼接测试场景 |

两张图集均为 **1536×1024**，每格 **256×256**，6 列 × 4 行，零边距、零间距。
TileSet 格子尺寸为 256×256；若在原森林中希望占用 128×128 世界单位，将对应地图层节点缩放设为 **0.5**。示例地形层为 0.25，以便同时展示更多素材。

把对应 `.tres` 赋给 TileMapLayer 的 tileSet，在瓦片面板选择需要的格子绘制。地形与透明元素使用两个不同的图层，装饰层放在地形层之后。

## 地形图集坐标

坐标从 0 开始，格式为（列，行）。

- 左上 3×3，即列 0–2、行 0–2：草地包围泥土的九宫格。四角、四边和中央泥土可分别使用，中间块和边条可以重复延长。
- 右上 3×3，即列 3–5、行 0–2：草地包围水面的九宫格。
- 最后一行：草地 A、草地 B、苔藓草地、泥土、石板地、碎石地。

这是可手工拼接的基础地形集，尚未配置 terrain peering 自动接边，也不包含覆盖任意凹形边界的完整内角集合。

## 验证与来源

- 图片由内置 imagegen 生成并修订；最终编辑提示词记录在 `docs/forest-kit-v2-generation.txt`。
- 检查了 PNG 实际尺寸、alpha 透明背景，以及所有 256×256 切片边界；边界上 alpha > 32 的像素为 0，避免切断相邻元素。
- 场景通过 Laya MCP 格式校验并已实际运行。运行截图确认地形拼接与透明元素叠放正常。
- 接边依据视觉检查，不承诺任意地形块互接或逐像素无缝；地形角、边需按上述方向摆放。
