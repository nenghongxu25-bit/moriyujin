# 森林侧壁瓦片 v1

用于当前方形森林地图的二维土层立面：草皮上沿、泥土碎石中段、底部碎石、左右收边和四个外角。素材由内置 imagegen 生成，参考当前 forest.png 和等距小样的土层底座；没有修改现有地表图集或正式森林地图。

## 文件

- `forest-cliff-wall.png`：真实透明背景图集，1254×1254。
- `forest-cliff-wall.tres`：已配置的 Laya TileSet，3×3，共 9 个格子，每格 418×418。
- `forest-cliff-demo.ls`：实际 TileMapLayer 预览，展示 7×3 横向延长、3×5 纵向加高，以及全部独立瓦片。
- `layout.json`：尺寸、名称与缩放数据。
- `generation-prompts.txt`：生成与修订提示词，使用内置 imagegen，无 CLI/API 调用。

生成器实际输出为 1254×1254，导入保留原始像素及 alpha，未强行重采样。配合原森林 128×128 格子使用时，将侧壁 TileMapLayer 的 scaleX、scaleY 设为 `128/418 = 0.3062200957`，每格实际占用 128×128 世界单位。预览使用不同缩放便于比较。

## 拼接方式

给单独的 TileMapLayer 赋予本目录 `.tres`。将侧壁放在上层地表边缘下方，结合地表层和人物层安排遮挡。

原始 3×3 可直接拼回完整立面。延长中间列时交替水平镜像，延长中间行时交替垂直镜像，接头使用相同的纹理端点，最后一个中间块恢复正常朝向后接外侧收边。示例：上沿为 `0, 1, 水平镜像1, 1, 水平镜像1, 1, 2`。中段和底边使用相同的列排列。

此方案可直接延长为奇数列/行的立面。不是任意瓦片之间均无缝；未提供偶数跨距专用端头，也没有完整凹角、四方向悬崖转折、terrain peering 自动接边、碰撞或寻路。不要将墙面上下翻转成不同朝向的悬崖，镜像仅用于上述中段衔接。纵向延长会镜像部分小石纹和根系，是本基础版本的外观限制。

## 验证

通过 MCP 校验场景结构，并在 Laya 编辑器实际运行截图检查 7×3 和 3×5 拼接；运行日志没有新的错误。截图：`../../../docs/forest-cliff-tiles-preview.png`（从项目根目录访问 `docs/forest-cliff-tiles-preview.png`）。

`tools/build-forest-cliffs.cjs` 从生成 PNG 的实际尺寸重建 TileSet 和示例场景，保留已有 UUID，不改 PNG。若已手工修改示例场景，重建会覆盖该示例场景，应先备份。
