# 森林地形 v3

这套补充草地与水、草地与泥土的双向边缘、凸角和凹角。保留 v2 的装饰元素，未替换原来的地图。

## 在 LayaAir 中查看

打开 `terrain-transitions-demo.ls` 并运行：左上是水包围草地（包含内部水洞），右上是泥土包围草地，左下是带凹口的池塘，右下是分叉土路。这些是实际 TileMapLayer 拼接，不是整张地图背景图。

`patterns/` 内四个 `.lh` 是对应的可复用预制体，可以拖进场景。默认缩放 0.25，每个逻辑地块显示为 128×128；演示场景缩放 0.125，显示为 64×64。

## 图集布局与组合

- `grass-water.png/.tres`：草地与水。
- `grass-dirt.png/.tres`：草地与泥土。
- 每张图片 1536×1024，6 列 × 4 行，每格 256×256，共 24 个源地块。
- 左上 3×3 为草地包围另一材质；右上 3×3 为另一材质包围草地；最后一行前三格纯草地，后三格纯水或泥土。

复杂轮廓由四个源地块组成一个逻辑地块，依据邻居选择直边、凸角、凹角或填充格。这里每个“角部”使用一个完整的 256×256 源地块，不是把单个格子再裁成四份。

`topology.json` 提供 47 种归一化二值邻接掩码及双向组合的四个源格编号。位定义：北 1、东 2、南 4、西 8、西北 16、东北 32、东南 64、西南 128；编号 `gid = 行 × 6 + 列`，从零开始。相邻两个正交方向不同时存在时，对应斜向位被忽略。

`tools/build-forest-transitions-v3.cjs` 是项目根目录中的离线组合脚本，生成 MCP 编辑请求及拓扑清单；不会自行应用场景修改。组合逻辑检查了两组材质、双向前景的 47 种邻接状态和 20 种角部类型。

## 验证与范围

四个示例已通过 MCP 在 LayaAir 中实际运行并截图。`terrain-47-patterns.ls` 展示两组材质各 47 种草地前景组合；图中相邻样本互相独立，不是一张连续地图，最后一格留空。

运行截图位于项目根目录 `docs/forest-v3-transitions.png`、`docs/forest-v3-47-patterns.png`。生成提示词见 `docs/forest-v3-generation.md`。

当前已支持上述双材质轮廓组合，但尚未配置 LayaAir 原生地形自动笔刷，也没有水与泥土直接相接、三材质交汇的专用过渡。AI 生成纹理仍可能有局部色差或接缝，47 种拓扑覆盖不等于每个像素都严格无缝。原有独立树木、石头、草丛等装饰继续使用 `../forest-kit-v2/elements/`。
