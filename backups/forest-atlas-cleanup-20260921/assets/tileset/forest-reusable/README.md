# 森林草地可复用地块 v1

## 在 LayaAir 中使用

- 打开 `grass-reuse-test.ls`，运行当前场景查看实际铺设效果。
- `grass-variants-v1.tres` 是已配置的 TileSet，赋给地图的 TileMapLayer.tileSet 后，在瓦片编辑面板选择已定义的地块进行绘制。
- 地图格子和贴图取样区域均为 **128×128**；间距和边距为 0。
- 共配置 **16 个基础草地变体**，用于草地内部混铺。
- 图像实际大小为 1254×1254。TileSet 从完整的 128×128 区域中选择地块，不使用右侧、底部不足一格的余量。不要把原图当作 4×4 图集切分。
- 已选取的图集坐标：x、y 分别为 0、2、4、6，共 16 个组合，坐标从 0 开始。

## 测试场景布局

场景由真正的 TileMapLayer 渲染，共 16 列、8 行、128 个地块。

- 第一行：依次展示 16 个变体。
- 第二行：同一地块连续重复。
- 后六行：固定随机种子的变体混铺。

场景缩放为 0.625 以同时展示更多地块；TileSet 的实际格子仍为 128×128。

本组是基础草地纹理，不包含泥地/河岸自动接边规则。地块边缘不是逐像素相同，已在实际运行场景中检查混铺视觉效果；不宣称任意组合数学意义上的无缝。
