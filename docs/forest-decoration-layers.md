# 森林装饰摆放

打开 `assets/scenes/forest.ls`，在 `Area2D` 下选择对应分类。

| 节点 | 放什么 | 行为 |
| --- | --- | --- |
| GroundLayer | 绘制地形瓦片 | 地图底层 |
| GroundDecorLayer / 地表装饰_落叶苔藓碎石 | 落叶、苔藓、贴地碎石 | 人物始终在上面，不挡路 |
| GroundDecorLayer / 地表痕迹_车辙血迹 | 车辙、血迹、脚印 | 人物始终在上面，不挡路 |
| ActorLayer / 可穿过装饰_草丛芦苇 | 灌木、草丛、芦苇 | 按落地点与人物前后排序，不挡路 |
| ActorLayer / 阻挡装饰_树木岩壁路障 | 树木、岩壁、倒木、路障 | 使用带 DepthObstacle 的预制体阻挡人物 |
| ActorLayer / 交互装饰_箱子设备 | 箱子、发电机等 | 交互与碰撞由各自预制体组件决定 |
| RoofLayer / 前景装饰_始终遮住人物 | 刻意放在最前面的枝叶、屋顶 | 始终盖住人物，不自动挡路 |
| LightingLayer / EffectLayer | 灯光 / 世界特效 | 使用原有功能 |
| LogicLayer | 触发器、刷怪逻辑等 | 不用来放普通装饰图片 |

已有 Characters、Enemies、Pines、Oaks、Rocks 等角色和采集物分类保留原行为。天气和水面节点也保留。

## 直接拖入的预制体

目录：`assets/prefab/forest-decoration/`。

- `阻挡_松树.lh`：树根碰撞，树冠可以从下方经过。
- `阻挡_岩壁.lh`：底部矩形碰撞，可调整范围。
- `可穿过_灌木.lh`：有前后遮挡，没有行走碰撞。
- `地表_落叶.lh`：放在地表装饰分类。

**分类节点负责整理，名字不会自动给 PNG 添加碰撞。** 要挡路，拖入“阻挡”预制体；换图时修改其“图片_可替换”子节点。若直接拖入 PNG，需要自行添加 DepthSortable（落地点）和 DepthObstacle（阻挡范围）。不要给整个分类文件夹加碰撞。

选中阻挡预制体根节点，在 DepthObstacle 中调整 blockX / blockY / blockWidth / blockHeight（节点内部坐标）；它们只覆盖物体贴地的实体部分，不应包住整张树冠或透明边缘。岩壁模板是近似矩形；不规则或很长的障碍可以在预制体内放多个带 DepthObstacle 的无图 Sprite 分段覆盖。缩放整个预制体，图片、落地点和碰撞会一起缩放。

ActorLayer 的分类文件夹在运行时由已有 ActorLayerGroups 展开，让人物与每件装饰在同一个父节点下排序；停止运行后仍按编辑分类显示。装饰直接放到这些分类节点下，不要再套一层文件夹。分类文件夹保持位置 0、缩放 1、旋转和轴心 0。新增交互分类仅负责整理，不自动生成开箱等逻辑。
