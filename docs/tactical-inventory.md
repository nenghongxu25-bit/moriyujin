# 战术背包与仓库

2026-09-21：重做背包和仓库 prefab，保留 UUID、场景实例 ID 和存档键。旧文件与村庄场景备份在 `backups/tactical-inventory-20260921/`。布局使用可编辑的 Laya 节点；控制器不在运行时创建界面。

## 当前可用

- 左侧为装备及四个快捷槽，中间为五列背包，右侧为六列仓库、搜索容器或物品详情。
- 仓库连续滚动，取消旧的 30 格分页限制；原有物品锚点不变，默认仍为 210 格。
- 多格物品拖拽、R 旋转、有效／无效位置提示、跨区转移，移动失败保持原物品。
- 拖拽落格保留抓取点偏移，按物品轮廓就近吸附；装备槽接受明显重叠，松手时重新计算目标。回归：`node tools/test-inventory-drag-targets.cjs`（同样使用独立 CDP 9234）。
- 拖拽时使用 prefab 内单独的物品显示节点，来源位置显示完整的独立空格；取消时恢复物品与遮挡格子，拖拽过程中不移除物品数据。运行截图：`inventory-drag-empty-cells.png`。
- Ctrl+点击快捷转移，Alt+点击装备；右键操作菜单；点选后可使用底部操作按钮。
- 同一物品在 250 毫秒内快速双击可转移，搜索容器里为拾取。慢速点击仅选中；跨物品、跨区域、拖拽或其他操作会打断双击识别。空间不足不移动。验证：`node tools/test-inventory-double-click.cjs`。
- 背包或仓库物品可直接装备，也可拖到装备槽；替换下来的装备回到来源区域，空间不足则取消整次替换。
- 背包和仓库分别整理、按数量拆分、查看详情；丢弃需在遮罩弹窗中确认。
- 搜索和分类使不匹配物品变暗，保持锚点不动；装备槽点击卸下，快捷槽点击分配／取回。
- 搜索容器中的物品按真实尺寸排布，可以拖入背包或使用快捷转移。

这次没有新增独立胸挂／口袋容量、背包嵌套、负重、保险箱或弹匣装填系统，也没有把之前仅绘制的 28 个物资图标注册成可掉落物品。旧非武器物资的停用和清理规则仍然有效。不能把当前版本描述为已经完整复刻两款游戏的所有物品系统。
