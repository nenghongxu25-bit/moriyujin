# 待办：天空、地平线与远近纵深表现

记录日期：2026-09-19
状态：暂缓实施，后续再评估；尚未选择技术方案。

## 用户目标

希望游戏画面能够看到天空，并呈现地平线、近大远小和向远处延伸的空间感。天空表现是用户最在意的部分。用户担心实现难度、三维素材制作成本及后续维护，因此决定先记录为待办，不立即改造项目。

## 已讨论的候选方向

- 保留二维场景，使用天空和远景背景增强构图；需要明确这不等同于完整的透视投影。
- 二维模拟透视：统一处理地面、角色、物体的投影与缩放，并适配遮挡和交互。
- 三维场景配合二维 Spine 人物，采用固定透视相机，玩法仍以地面移动、战斗和采集为主。可先用平面和方块等简单几何体搭建原型，不以精细建模为前提。
- 菱形或等距地图不等同于近大远小，也不会自然满足天空和地平线的构图目标。

## 重新评估时的步骤

1. 先确定参考画面、天空在构图中的位置，以及固定镜头下希望看到的远景范围。
2. 做独立小场景原型，验证天空、地平线、Spine 人物贴地、移动、瞄准和建筑遮挡。
3. 在手机尺寸下检查远处目标的可读性和操作体验。
4. 再评估现有 TileMap、场景素材、碰撞、射击、室内遮罩及光照系统的复用和迁移成本。

## 验证边界

尚未制作天空或透视原型，也未验证本项目的三维与 Spine 混合方案。此前工作量讨论仅为粗略工程判断，不是经原型验证的工期承诺。本次只记录需求，不修改游戏场景或运行逻辑。
