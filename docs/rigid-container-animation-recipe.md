# 给后续 AI 的容器动画复用操作单

适用：本项目等距视角的刚性箱盖、柜门、纸箱折盖。目标是防止播放时主体伸缩、纹理跳变、接缝断裂。先按本文操作，不重新探索整帧生成和遮罩拼接路线。

## 最短执行入口

已完成样件：`cardboard_box`、`kitchen_cabinet`。

- 实现模板：`tools/build-v4-rigid-animation.ps1`。
- 图层与参数证据：`art/loot-points-v4/rigid-layers/{id}/`。
- 实际补图提示词：`docs/v4-rigid-rebuild.md`。
- 可暂停、逐帧检查：`docs/v4-rigid-preview.html`。

现有两个物件需要重建时，直接用脚本，不再调用图像生成。新物件复用算法、修改专用素材和几何参数，不照搬旧物件像素坐标。该脚本目前硬编码两种物件，不能直接换个 ID 就当通用生成器。

在项目根目录 `D:\Desktop\测试\测试` 执行：

```powershell
# 只生成候选帧、并排图、几何数据和像素检查结果；不覆盖项目动画
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-v4-rigid-animation.ps1

# 看过候选逐帧图及播放效果、确认通过后才运行
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-v4-rigid-animation.ps1 -Publish
```

不要将 `-PrepareOnly` 和 `-Publish` 一起使用。`-Publish` 的程序检查仅覆盖固定表面采样和边缘裁切，不包含人工目视验收，也不等于完整质量保证。

## 核心原则：一份主体、一份部件、多组角度

每一帧都重新从**同一张完整主体**开始绘制，再变换**同一张部件纹理**。逐帧变化的只能是部件角度及必要的遮挡顺序。

不得让四帧分别使用四张生成主体；不得拿旧关闭图和旧打开图随手圈区域互相覆盖。主体固定并不能自动解决活动部件形变，门板或纸盖本身也必须复用同一份纹理和几何尺寸。

## 第一步：先得到完整的固定主体

1. 保留原图与修改前备份；新结果先输出到候选目录。
2. 准备真正无门、无盖的完整主体：柜子要有完整框架、侧面、顶部、内壁、层板；纸箱要有完整四面箱壁、内底和上沿。
3. 若原图中这些位置被门盖遮挡，用图像编辑一次性补齐。仅要求生成单张无门/无盖主体，不要求生成四帧。
4. 检查补图透明度、孤立碎片和完整轮廓。新生成图不能假定尺寸、坐标与原图一致。
5. 主体只做一次等比缩放和定位，输出固定 `body.png`。先预留门盖完全打开的空间；后续不得按各帧可见包围盒分别缩放、靠底或居中。

本次 `Prepare` 将柜体约束在 340×396 范围、纸箱约束在 340×285 范围，固定下沿 476，画布 512×512。这些是本次构图参数，不是新物件的通用坐标。

## 第二步：每块活动部件只提取一次

从现有清晰素材或单独补绘的图中提取门板/盖板，保存独立透明图层。提取范围不能包含柜框、箱壁、邻近纸盖或背景碎片。

模板的 `Part(...)` 用三个源点定位一个平行四边形纹理：

| 参数 | 含义 | 标定办法 |
| --- | --- | --- |
| `a`、`b` | 素材中部件同一铰链边的两个端点 | 沿门的竖边或盖的折线取点 |
| `c` | 素材中与 `a` 相邻的自由边角点 | 第四角由 `b+c-a` 推导 |
| `hinge`、`end` | 最终画布上的两个固定铰链端点 | 贴合 `body.png` 的门框边/纸箱上沿，所有帧不变 |
| `closed` | 关闭时从 `hinge` 指向自由角的二维向量 | 根据关闭时实际覆盖范围确定，不是绝对坐标 |
| `normal` | 竖直门转至 90° 时的宽度投影向量 | 与项目观察方向一致，所有帧固定 |
| `rise` | 水平箱盖转至 90° 时自由边上升的像素量 | 对应盖深和视角，所有帧固定 |
| `vertical` | 是否是绕竖直轴转动的柜门 | 门为 true，水平折盖为 false |

取点全部使用实际输入图的像素坐标。原图坐标和最终 512 画布坐标不能混用。`a,b,c` 不能共线。

## 第三步：用固定轴计算中间帧

沿用模板 `Panel.Draw` 的计算，不为各帧重新手动调部件宽高：

```text
θ = 角度 × π / 180

柜门：d(θ) = closed × cos(θ) + normal × sin(θ)
箱盖：d(θ) = closed × cos(θ) + (0, -rise × sin(θ))

目标三点：hinge、end、hinge + d(θ)
第四点：end + d(θ)

Map(a,b,c → 目标三点)，绘制同一张部件纹理，再重置绘图变换。
```

两根轴端点不会移动。门盖因转动出现投影变窄属于正常变化；铰链漂移、纹理自行更换、主体轮廓跳动不正常。

本次可照抄的角度和顺序：

| 部件 | 四帧角度 | 合成顺序 |
| --- | --- | --- |
| 柜子左门 | 0、24、62、110 | 先左门，再右门 |
| 柜子右门 | 0、32、68、100 | 右门终点角度为避免超出画布调整过 |
| 纸箱内层短盖（0、3） | 0、0、55、155 | 所有纸盖顺序为 0、3、1、2 |
| 纸箱外层长盖（1、2） | 0、65、130、155 | 先开启外层，后开启内层，避免穿插 |

对新物件，角度、遮挡顺序和两组投影向量需根据同一几何模型标定，不能逐帧任意调整。门盖背面明显可见时需准备固定背面纹理，避免把外侧把手翻到内侧。模板是二维仿射近似，不能直接保证任意透视、复杂连杆或软布动作正确。

## 第四步：合成和透明边缘

每帧创建相同尺寸透明画布 → 原位绘制同一个 body → 按遮挡顺序绘制活动部件 → 必要时绘制同一个前沿遮挡层 → 导出。

本次生成主体内部 alpha 为 253，GDI+ 多次透明合成会使静止像素出现约 1～2 级 RGB 舍入变化。模板仅对不透明木头/纸板中 alpha>240 的像素恢复为 255，保留边缘抗锯齿。不得将此操作直接套到玻璃、薄纱等真实半透明材质。

不要对整帧一律只保留最大连通块：展开部件、细铰链可能被误删。发现残片先定位其来源，在对应源图层清理。

## 第五步：以下条件都满足才交付

1. **来源检查**：各帧共用同一个主体及部件纹理。中间帧没有引用旧的整帧形变图片。
2. **固定表面检查**：在不会被门盖遮挡的主体区域逐像素比较，要求一致。新物件重新选区域；不要故意选一个极小区域绕过问题。
3. **铰链检查**：`geometry.json` 中同一 panel 四帧的前两个角点完全相同。其余角点应由固定参数和角度推导。
4. **完整性检查**：所有投影角点和有效像素均在画布内；打开状态不裁切。不允许用缩放某一帧的办法救回裁切。
5. **视觉检查**：查看关闭、中间、全开每一帧，以及连续和慢速播放；浅底、深底检查接缝、洞、残片、穿插、反面纹理。查看原尺寸和游戏显示尺寸。检查不通过就继续改候选，不能直接发布。
6. **接入检查**：发布后项目 PNG 与候选 PNG 一致，原 UUID 保留；项目内实际点击确认播放。资源可加载、能播到最后一帧只证明接入成功，不证明图案不变形。

本次已记录的静止表面比较次数为纸箱 11,304、吊柜 43,695。该数字仅是本次固定采样区域的证据，不是新物件需要达到的固定指标，也不能代替视觉检查。

## 交接清单与节省重复工作的约定

保留：固定主体、独立活动图层、原始来源、完整补图提示词、几何参数、角度序列、候选四帧、预览入口、检查报告、修改前备份、重建命令。让后续 AI 能重建，不必猜测聊天记录里的坐标。

复用优先级：已有样件和脚本 → 修正该物件参数/图层 → 缺少被遮挡表面时才补图。不要为了做中间帧重复调用生成工具。只更新有变化的经验，勿将整个操作日志放进 AGENTS.md。

可直接复制给另一个 AI 的任务说明：

> 先阅读 AGENTS.md 和 docs/rigid-container-animation-recipe.md。复用 tools/build-v4-rigid-animation.ps1 的固定主体＋独立刚性部件方法制作容器开启动画。禁止独立生成四张整物图后用遮罩修补；只生成缺少的完整主体/部件。先在候选目录完成一个物件，保留同一主体、固定铰链和一份部件纹理，通过固定像素、几何、裁切、逐帧与连续播放检查后再发布。不能将加载成功或到达最后帧说成无形变。新物件修改专用坐标和角度，不覆盖现有样件。交付可重建的图层、参数、脚本和明确预览入口。
