# 固定火光

备份：`D:/Desktop/测试/backups/fire-light-20260917-121651`。

`Area2D/fire/fire1` 已替换原白色硬圆，使用柔边暖色纹理。节点位置和 523×479 尺寸保留；移动节点调整位置，调整宽高或缩放改变照明范围。这里是照明范围，不是火焰动画。

`FireVisualLight` 组件暴露“照明强度”（默认 0.9）和“暖色强度”（默认 0.16）。照明通过绑定的 `Nightlayer/fire1_cutout` 扣除夜色；暖色位于夜色之上、房间遮挡之下。室外不会覆盖房间中心的黑色遮挡，房间柔边仍保持其渐变效果。白天停止扣除夜色，但保留淡暖色。

火光固定在地图坐标中，现有手电照常工作。两张 256×256 纹理由 `tools/bake-fire-light.cjs` 离线生成；没有实时模糊、逐帧生成纹理或新增全屏 RenderTexture。静止状态不主动重缓存，玩家移动时仍可能更新现有夜色缓存，因此不代表动态合成零开销。

第一版不含闪烁、火焰动画、墙壁挡光。添加第二盏灯时必须同时建立独立扣除 Sprite 并绑定，不能让多盏灯共用同一个扣除节点。

验证：TypeScript 编译通过；逻辑检查覆盖世界坐标对齐、玩家移动、静止 120 次更新无额外缓存请求、隐藏光源及昼夜切换。通过 Laya MCP 预览确认火光独立照明、移动后光留在地图位置、室外房间遮挡及进入关灯房间后的局部照明。截图见 `fire-light-preview.png`、`fire-light-offset.png`、`fire-light-room-hidden.png`。这次没有进行手机性能测试。测试用的玩家位置、手电开关和房间开关已恢复。
