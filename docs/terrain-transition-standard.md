# 双材质交接地块标准

用户形状参考：`assets/tileset/forest/reference/grass-dirt.png`。

每对材质使用左右两组 3×3 九宫格：一组 A 包围 B，一组 B 包围 A。四角采用圆润转角，四边负责延长，中间为纯材质。边界可保留细碎起伏，但跨格接头的位置、宽度、方向与纹理必须对应。形状参考不决定材质画风；纹理和配色沿用目标地图素材。

## 以后制作与验证

### 材质过渡带试作

当前图集在不规则边界版基础上加入内置 imagegen 绘制的材质交接细节：草泥采用稀疏草叶和露土，水岸采用湿土、岸石与浅水底色，石泥采用碎石和泥土填缝。通过 `tools/apply-forest-transition-bands.ps1` 限制到轮廓附近；四周 8 像素、中心填充块和过渡区域外像素保持不变。

导入区域在名义轮廓两侧各最多 32 像素内，中间部分使用生成细节，外围平滑回到原图。不是将整张生成图替换原图，也不是对原图做模糊。由于接头必须保留旧像素，过渡在接头附近会收窄，旧素材的接口外观仍然保留。

备份与生成原稿：`backups/forest-transition-20260919-190112/`。该目录的 forest.png 可恢复到这次过渡带修改之前。

### 当前启用的不规则边界版本

在圆角版基础上，`tools/irregular-forest-terrain.ps1` 对材质分界附近作最大约 6 像素的非等周期位移。每格四周 8 像素严格锁定，距离边缘 8–24 像素之间平滑恢复起伏；中心填充块与 alpha 不变。纹理从原图取样，不使用生成稿的重绘纹理。

此版本允许直边块的内部边界轻微起伏，替代上一版“全部直边块不变”的限制。保持原有切片接口，不承诺任意地块组合无缝。更新前备份位于 `backups/forest-irregular-20260919-184429/`。

1. 先确定两种材质与正反包围关系，再确定切片接口。
2. 采用参考的圆润转角；自然起伏在格子内部变化，接头处须可衔接。
3. 纯材质和直边分别验证横向、纵向重复；角块验证四方向及正反包围。
4. 凹角、狭窄通道、分叉与多材质交汇按实际需求补齐，不能只凭图集外观宣称完整自动拼接。
5. 更新已有图集前备份原 PNG 与元数据，检查尺寸、alpha、切片与资源引用，再在场景中预览。
