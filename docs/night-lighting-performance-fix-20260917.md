# 灯光缓存修复（2026-09-17）

## 修改

- `DynamicCutoutProbe.positionSmoothTime` 默认值及 city 场景值改为 0。光层整体跟随玩家；关闭位置滞后时，直接赋值目标坐标，避免浮点抵消误差造成极小的内部位移。
- 保留 0.045 秒方向平滑、bitmap 隔离和 destinationOut 混合。
- 用引擎公开的 `Sprite.setSelfBounds` 固定缓存边界，覆盖背景和两张光照 Sprite 在所有旋转角度下的完整矩形。当前场景缓存大小为 1758×1758；没有裁掉透明角落来缩小范围。
- 使用预先分配的 Rectangle，只有边界实际变化才设置新边界并请求刷新；不创建额外 Sprite、纹理或滤镜。
- 渐变 PNG、光束/环境光参数和 UI 层级未修改。

持续转向依然需要更新现有缓存内容。本修复主要消除移动的位置滞后刷新，以及旋转时不停改变 RT 尺寸的行为，不宣称动态画面零重绘。

## 验证结果

- TypeScript noEmit 检查通过。
- 对多组纹理尺寸和正/负源点偏移进行 360° 角点覆盖检查，所有角点都在固定边界内。
- 已运行真实 city 预览并检查截图，当前主光束、散射、环境光和独立 UI 仍可见。
- 将现有编辑器切换到前台后，已完成 16 段有效采样，所有段均记录 `documentHidden=false`、renderFrames 与采样帧数一致。
- 四种场景全部观察到 RT 尺寸更换为 0，动态段保持 1758×1758。
