# 森林区域分布草案

这是区域规划，尚未修改场景或填充地图。方位按编辑器画面上下左右描述；现有三个出口和玩家位置暂时保留。以下危险等级、资源和路线是设计建议，尚未接入游戏逻辑。

## 总体结构

森林占主体，建筑作为探索目的地。主路形成一条环线，支路通往河岸、营地和地堡。不同区域之间用树林与缓冲空地衔接，不做整齐的方形分区。

| 方位 | 区域 | 建议布置 | 探索用途 |
| --- | --- | --- | --- |
| 下方偏右 | 林缘补给点 | 旧皮卡、小篝火、背包，留开阔落脚地 | 适合当前玩家位置附近的初始探索；低危险 |
| 下方偏左 | 废弃林屋 | 木屋、旱厕、破围栏、少量灌木 | 初期搜刮、环境叙事；低至中危险 |
| 中央偏左 | 伐木场 | 锯木厂、原木堆、树桩、工具箱，外围疏林 | 木材与工具目标；中危险 |
| 中央 | 林间道路与岔口 | 碎石、倒木、路边痕迹，保持主路清楚 | 导航与区域连接；少放建筑 |
| 右侧 | 河岸湿地区 | 沿实际水体放芦苇、泥岸，窄处布桥 | 自然边界与侧向路线；水面和通行规则待单独实现 |
| 上方偏左 | 深林废弃营地 | 帐篷、熄灭篝火、背包，密林遮挡视线 | 可选探索支路；中危险 |
| 上方偏右 | 军事检查站 | 岗亭、瞭望塔、油桶、发电机、路障 | 显眼的高价值目标；高危险 |
| 最上方偏内侧 | 隐蔽地堡入口 | 岩壁、地堡门、枯树，支路绕入 | 深入探索终点；高危险 |

## 路线

主环线：林缘补给点 → 废弃林屋 → 伐木场 → 中央岔口 → 军事检查站 → 河岸回路 → 林缘补给点。

支线：伐木场 → 深林营地 → 隐蔽地堡；军事检查站附近另留一条绕行小径，与地堡支线连通。

三个现有出口作为回撤点，落地布局时接入邻近路线，不移动或重复创建跳转逻辑。不要让高危险区域堵住所有返程路线。

## 摆放尺度

- 约六成视觉面积留给树林、空地和自然过渡，其余分配给据点与道路。
- 树木采用疏密变化的簇群，避免均匀撒点或用同一株树排成整齐墙面。
- 主路至少容纳两个人物并排，支路至少留一个人物加余量；实际宽度按玩家碰撞体试走校准。
- 每个据点预留一个主入口与一个可识别的绕行口。木屋和地堡图片本身不代表已经支持进入室内。
- 岩壁、树根、围栏实体部分用阻挡装饰；落叶和车辙放地表层；稀疏灌木、芦苇按需要放可穿过装饰。
- 第一轮只摆主要地标、道路和阻挡边界，试走连通后再补小装饰。
