# Forest 天气运动诊断（2026-09-19）

## 最新实现：固定屏幕天气（替代以下全部跟随试验）

用户要求玩家移动不改变雨雪相对屏幕的速度。WeatherLayer 现位于场景根下独立、没有 Camera2D 的 `ScreenWeatherArea/WeatherLayer`，与地图 Area2D 分开。使用 `ScreenWeatherEmitter` 和 Local 模拟，只响应窗口 RESIZE，不读取玩家位置、地图相机或其缩放。雨雪仍使用克隆的双面材质；未新建运行时 UI。

运行验证：临时诊断读取同一颗雪花的实际粒子缓冲数据及绘制相机标志，按引擎公式计算屏幕逻辑坐标。出生时间 0.3833 的 slot 0，在玩家移动期间 x 始终为 380.52396，y 从 433.99283 递增到 657.17368，速度始终为 (0,63.16677) 逻辑像素/秒；发射器始终 (667,375)，绘制 CAMERA2D=false。记录保存在 `weather-screen-verification.json`。未启用额外速度模块，以上位置计算不遗漏额外速度。

诊断期间临时保持后台绘制，避免编辑器失焦导致截图及粒子时间冻结；验证后已删除诊断代码及强制绘制设置。TypeScript 检查通过。该验证证明相对屏幕的运动独立，不代表雪花相对滚动背景不存在视觉相对运动。

## 当前实现：独立世界天气层跟随相机（取代下方试验）

- WeatherLayer 位于 `Scene2D/Area2D/WeatherLayer`，不再是玩家子节点。人物镜像、后处理和遮挡拷贝不再包含天气。
- `src/Player/CameraWeatherEmitter.ts` 跟随玩家 Camera2D 的位置；Box2DShape 覆盖视野及 256 单位边缘，避免快速移动离开发射区。雨雪采用 World 模拟，已发出的粒子不随发射器整体搬动。
- 雨雪材质各克隆一份并设置 CULL_NONE，不改共享素材。实测仅改变位置跟随仍会在右移/上移时丢失雨雪；双面显示后两方向均可见。不要把此前“仅抵消父节点镜像就足够”的判断当作最终结论。
- `PlayerAttachedWeather` 试验脚本已移除。PlayerCamera2D 无天气代码；临时日志、矩阵替换和人物后处理覆盖已撤回。
- TypeScript 检查通过；MCP 预览右移、上移截图保存在 `.tmp/weather-camera-final-right.png`、`.tmp/weather-camera-final-up.png`，雨雪可见且人物与枪械对齐。自然的镜头相对运动仍存在，不宣称所有方向的视觉速度完全相同。

## 后续试验：人物子节点方案

按用户要求，已将 forest 场景中的 WeatherLayer 从场景根节点移至 `Area2D/ActorLayer/prefab_player/WeatherLayer`，局部位置设为 `(0,-224)` 以覆盖视野上方，保持雨雪 Local 模拟和原有粒子参数。只修改森林实例，不修改共用玩家或天气 Prefab。MCP 预览确认雨雪可见；是否改善用户感受到的运动仍需用户对比，不能将此试验等同于已解决。天气现在继承玩家变换（包括朝向镜像），这是直接照搬身体粒子挂法的取舍。

以下是修改前的诊断记录：

通过临时只读日志，记录 Camera2D、天气节点全局矩阵、粒子 shader 的 u_NMatrix、实际绘制的 CAMERA2D / RENDERTEXTURE 标记。数据来自 MCP 的 Play 日志；诊断后移除临时代码。

实测向右移动：玩家 x 从 583 变到 950.949，相机全局 x 从 1460 变到 1827.949；WeatherLayer 一直为 (595,151)，snow 的全局坐标及 u_NMatrix 平移一直为 (591,-137)，rain 为 (591,-123)。simulationSpace=0。

实际粒子绘制的全局及 pass shader 数据均未启用 CAMERA2D。普通 pass 的逆矩阵为单位矩阵；另有离屏 pass 的固定逆矩阵 [1.25,0,-271.25;0,1.25,-123.75]，同样未启用 CAMERA2D，未随上述玩家位移变化。

结论：本次测量中，天气是屏幕固定层，地面则受玩家相机影响。相对地面的雪花速度 = 屏幕雪花速度 - 屏幕地面速度；地面速度约为负的相机速度，因此会呈现用户描述的同方向加速。这不是已验证的相机反向补偿错误。上次仅修改 Local/World 不会改变是否使用相机。

下一步若要让雪融入场景：应考虑将天气置于地图相机所属 Area2D 内，使用世界空间粒子，并让发射范围覆盖当前视野；可移动发射区域，但已发射雪花不随其整体移动。需要单独实现与运行验证，本次诊断未修改该行为。
