# 森林轻微水面流动

正式场景 `assets/scenes/forest.ls` 的 GroundDecorLayer/ForestWaterFlow 使用 `ForestWaterFlow.ts`，位于积雪、积水覆盖层之前。复用已生成的 128×128 水纹 `assets/tileset/forest/water-flow.png`，不修改原瓦片图集、碰撞或河岸。

- speed：默认 12（原 1.2 的 10 倍）；amplitude：默认 5 像素（原 0.7）。按用户要求加强流动和起伏，河岸不动。两者均设为 0 可静止。
- 禁用节点/组件后显示原始静态水面。
- 使用现有森林图集继续铺水后，重新进入场景即可自动读取地面范围和水域。无需逐块配置动画。
- 范围在场景初始化时读取，不实时追踪运行中修改的瓦片。识别依赖当前图集的水色，换图集、旋转瓦片或使用不同颜色水域时需要重新验证遮罩。
- GroundRain/GroundSnow 同时在初始化时自动匹配地面范围，原有手动编辑器范围仅作初始值。

验证：TypeScript 编译、流动生命周期/暂停时间上限/清理、雨雪回归及地面范围测试。MCP 预览确认水面材质启用，7680×6784 覆盖范围，流动偏移随时间递增，并截图检查河岸；临时传送和日志已移除。
