# 环境闪电

最新试调：四种预设随机选择（单次强闪、弱闪后强闪、1—111、云内闷闪），避免连续重复。每次触发时长变化 ±10%，强度乘数为 0.9～1.05，最终限制在 0～1；1—111 的中间黑暗停顿仍固定 1 秒。闷闪使用平滑低亮度起伏。未新增渲染层、纹理或逐帧随机。备份 ../backups/lightning-patterns-20260917-211824。确定性逻辑检查覆盖四种预设、24 轮无连续重复、固定停顿与 alpha 恢复，类型检查通过。

当前试调（2026-09-17）：间隔已改为 2 秒；节奏为 1—111。第一次闪光带约 0.16 秒短余光，完全淡出后停顿 1 秒，再以约 0.1 秒间距闪三下。三下余光相连，强度分别为 0.85、0.7、1 倍，最后一次约 0.4 秒衰减。lightningDuration=0.5 现在控制各次脉冲的时间尺度，整段含停顿约 1.76 秒。仅修改 LightningFlash.ts，备份见 ../backups/lightning-afterglow-20260917-210350。逻辑检查通过：四个亮度峰值、1 秒黑暗停顿、连续余光、恢复原始 alpha；类型检查通过。

NightMask 的 DynamicCutoutProbe 新增可调参数：lightningEnabled（默认开启）、lightningIntensity（0.88）、lightningDuration（0.5 秒）、lightningMinInterval（8 秒）、lightningMaxInterval（18 秒）。间隔从上次闪电结束算起。关闭 lightningEnabled 即恢复普通黑夜。

弱预闪、短暂间歇、强主闪、衰减结束。仅改变已合成的室外黑夜层 alpha，不添加 UI、滤镜或纹理，也不为闪电调用 reCache。室内遮罩和 UI 不参与闪光。白天黑夜层不可见时停止闪电，组件停用时恢复闪前 alpha。

这是揭亮地图原色的环境闪光，不额外加入冷白色覆盖层或雷电图形。后续天气系统可以控制 lightningEnabled。
