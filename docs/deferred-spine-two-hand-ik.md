## 期望效果

摇杆控制枪械的位置和旋转，左右手分别跟随前后握把，通过双骨骼 IK 自动带动上臂、前臂。

## 已验证事实

- 在 city.ls 的编辑器预览中，通过 MCP 日志和截图验证：修改玩家 bArmUR 骨骼旋转 ±55° 可改变手臂画面及手部位置，同时动画继续播放，Spine 节点与外部枪械节点 rotation 均保持 0。
- 实验关闭了该渲染实例的缓存，使用内部 render 钩子，在动画应用后、骨骼世界变换和渲染前修改角度。实验代码已撤回。
- MCP 定位玩家资源为 assets/spine/player/npc_young.json，导出版本 4.1.24；该文件未配置 ik 或 transform 约束。
- 左臂链为 bArmUL → bArmLL，右臂链为 bArmUR → bArmLR；现有 weapon 骨骼挂在 fistR 下。

## 后续方案与待验证项

- 可在 Spine 中配置左右手双骨骼 IK，使用独立目标；也可保留外部 Laya 枪械节点，将前后握持点转换到 Spine 坐标系后驱动目标。
- 枪械控制不能依赖被约束手臂的子级，避免循环依赖。
- 需处理握持点与手掌偏移、手腕朝向、肘部弯曲方向、目标可达范围、角色翻转，以及换弹时 IK 与动画的混合。
- 双手 IK 尚未在本项目实测；上一轮只验证了单骨骼旋转。缓存开启及抖音真机表现也未验证。
