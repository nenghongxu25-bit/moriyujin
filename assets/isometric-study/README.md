# 菱形地块独立试样

打开 isometric-study.ls，运行当前场景。

7×7 范围，去除四角后共 45 块草地/泥地，配有 15 个树木、围栏、箱子和灌木摆件。每块地面与每个摆件都是独立 Sprite，可在场景中单独选择、移动和替换。

这是固定视角的 2D 美术试样，不是 3D 模型，也没有迁移原地图。地块表面按 128×64 菱形排列，PNG 另含约 16 像素土层侧面。投影公式：x=667+(列-行)×64，y=155+(列+行)×32。摆件按落地点前后排列。

当前是静态视觉验证，尚未接入角色移动、碰撞、采集或 TileMap 自动绘制；原 forest/city 地形、游戏逻辑和入口未替换。正式采用前还需完善地块边缘、落地阴影和动态排序。

素材由内置 imagegen 生成，source-sheet.png 是原始透明图集；六个独立 PNG 是切分结果。tools/build-isometric-study.cjs 仅准备场景编辑请求，场景通过 MCP 写入。IsometricStudyBackdrop 只在预览此场景时设置米色背景。
