# 火把循环动画素材

目录更新：动画帧和图集在本目录；静态木柄位于 `../../decorate/fire/torch-body.png`，原始参考图位于 `../../decorate/fire/torch-concept.png`。HTML 预览和动画配置已使用这些相对路径。

双击 `torch-preview.html` 可播放组合预览，默认 8 fps，可暂停或调整速度。原始 `torch-concept.png` 保留。

- `torch-body.png`：固定木柄和缠布，透明背景，1254 × 1254。
- `torch-flame-sheet.png`：透明火焰图集，1536 × 1024，4 列 × 2 行，共 8 帧。
- `torch-frames/`：按行优先顺序切分的 8 张独立 PNG，每张 384 × 512。
- `torch-animation.json`：通用帧尺寸和组合坐标说明，不是 Laya 原生 atlas。

这次交付的是动画素材和独立预览，未挂接游戏场景。接入时固定木柄，预加载火焰纹理并按帧切换，不需要每帧生成纹理或使用实时模糊。预览采用逐帧播放，生成式素材的相邻帧可能仍有轮廓变化，可通过速度滑块选择合适节奏。

## 生成记录

使用内置 imagegen，以原始 torch-concept.png 为参考分别生成木柄层和火焰图集；独立帧仅作矩形切分，未重绘。实际输出木柄尺寸为 1254，而非提示请求的 1280；组合坐标按实际尺寸设置。

木柄提示：保留参考图的木柄、金属环、缠布、比例与位置，删除火焰、火星、烟和光晕；顶部恢复焦黑缠布及少量余烬，透明背景，无文字，不改变木柄造型。

火焰提示：仅使用参考火焰的橙色外焰、金色中层和浅黄色核心绘画风格；生成 1536×1024、4×2 的八帧透明图集，每格384×512，根部位置固定。按时间顺序从左倾、直立、分叉、右侧升高、右倾、右侧收缩、左侧升高到回到起始形态；变化适度连续，不含木柄、缠布、金属、文字、网格、烟和独立火星，根部柔和透明。
