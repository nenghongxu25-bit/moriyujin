# 标准独立火焰

把 standard-fire.lh 拖进场景需要燃烧的位置。节点原点在火焰根部，默认192×256，可调整 scaleX / scaleY 和 alpha。编辑器显示第一帧，运行后以8帧/秒循环，副本随机错开起点。

StandaloneFire 组件可调整每秒帧数、随机播放起点。共用现有 torch-flame-sheet.png，按4列2行读取8帧；存活实例共享纹理区域，每次换帧仅更换 Sprite.texture。禁用后由引擎停止组件更新，最后实例销毁时释放区域纹理。

此预制体仅提供火焰动画，不包含燃烧伤害、蔓延、烟雾或 NightMask 扣除。可作为后续火焰笔刷摆放的基础单元。
