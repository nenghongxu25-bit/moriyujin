# 破旧灰瓦双坡屋顶

这是原生 TileMapLayer 瓦片集，匹配砖墙的 256×128 等距网格和 256 墙高。
首版为 **7 格固定跨度** 的双坡屋顶，沿屋脊可接长（至少两列）。暂不支持任意跨度、L 形转折或交叉屋脊。

## 在哪里画

- 当前 `brick-wall-sample.ls` 中选 `ActorLayer / House_01 / RoofLayer`，进入瓦片绘制工具。
- 瓦片集：`slate-roof.tres`，两个分组 `Ridge U / grey slate` 和 `Ridge V / grey slate` 对应两个朝向。
- 每组 3 行 × 7 列：第一行是可重复的中段，第二行是起端，第三行是末端。
- 每行从左至右是横跨屋顶的第 1～7 条带；第 4 块是屋脊，两端是檐口，中间是坡面。
- 沿屋脊顺序铺“起端 → 若干中段 → 末端”；每段横跨屋顶需依次铺满 7 块。等距网格中两条建筑轴是两条斜向，不是屏幕水平/垂直。
- `slate-roof-layer.lh` 是空的屋顶层预制体，可用于自己的地图。屋顶必须独立于墙层；不要挂 BrickWallTileLayer。
- 编辑室内时可手动隐藏 RoofLayer；运行时现已按同一房屋内的室内地板自动淡出屋顶，详见下节。

## 结构和制作

共 42 块，包含两坡、连续屋脊、檐口、端部及端部砖山墙。屋脊高 424，墙顶高 256，檐口外挑 1/8 格。
单片图 320×640，锚点 (160,560)，图集各 2272×1936，2px 留边、4px 间隔。
端部砖山墙复用现有砖材质。原墙层绘制数据不变，只添加独立屋顶层。

灰瓦母图由内置 imagegen 生成，提示词保存在 `docs/slate-roof-prompt.txt`。
`tools/bake-slate-roof.ps1` 以统一几何投影材质；`tools/build-slate-roof.cjs` 建立切片和空预制体，不改现有试样。
`RoofTileLayer` 保留编辑器中的瓦片绘制数据，运行时在公共 ActorLayer 中建立屋顶显示层，避免嵌套房屋节点破坏人物、墙和地板的前后关系。不增加地面碰撞。
加入屋顶前的场景备份：`archives/brick-wall-before-roof-20260921.zip`。

## 按室内地板自动隐藏（2026-09-21）

使用 `house-template.lh` 空房屋预制体，拖到场景的 `ActorLayer` 下。每栋房子分别包含：

```
House（HouseRoofVisibility）
├─ IndoorFloorLayer  只画这栋房子的室内地板
├─ BrickWallLayer    画墙和门洞
└─ RoofLayer         画对应屋顶
```

保持三个子节点名称，复制整栋 House 即可保留绑定。不要把几栋房子的室内地板合到一个 House 里。房屋容器可平移、缩放；当前墙体不支持整体旋转。
正式玩家从 PlayerController.activeInstance 自动获取，脚底偏移与移动碰撞一致；试样在 House 的“玩家”属性中引用 WalkHere。复制到正式森林场景时清空这个试样引用。

玩家脚底踩到 IndoorFloorLayer 中任一已绘制瓦片就淡出本屋顶，空格不会触发。支持地板子层、父节点缩放和位移。退出地板连续 0.2 秒后才开始恢复，淡入淡出各约 0.2 秒；快速折返会平滑反向。各房屋独立判断。
地板应铺满室内、延伸到门洞，漏铺的空格视为室外。试样复用现有土地纹理演示，以 0.25 缩放的较小地板格贴合墙边；可以替换地板材质，判断不依赖具体瓦片编号。

试样已验证进门隐藏、出门恢复和再次进入。自动测试覆盖不同房屋、地板空洞、坐标缩放、脚底偏移、边界抖动和组件停用恢复。
自动隐藏改动前备份：`archives/house-before-auto-roof-20260921.zip`。

## 屋顶与墙材质拆分（2026-09-21）
灰瓦图集现在只包含瓦面、屋脊和檐口，不再包含砖砌山墙。屋顶仍为原来的 42 块，UUID、编号、尺寸和锚点保持不变。跨度仍为 7 格，本次不改变屋顶形状规格。
砖山墙另存为 `assets/tileset/buildings/walls/brick/brick-gable.tres`：两个朝向各 7 块；独立图层预制体为 `brick-gable-layer.lh`。以后其他墙材质可以提供自己的山墙图集，灰瓦图集无需跟着换。
当前试样保留砖房外观：`House_01 / RoofLayer / GableLayer` 是可独立绘制和替换的砖山墙层，显示顺序 99999，低于灰瓦屋顶 100000。放在 RoofLayer 下是为了随屋顶一起淡出，不代表它是灰瓦的一部分。删除或替换 GableLayer 不影响屋顶绘制。
空屋顶预制体和空房屋模板不附带砖山墙；需要时自行加入对应材质的山墙层，并沿屋脊正向末端依次铺 7 块。固定等距镜头下背向端面的外立面不可见，不需要绘制背面山墙。
制作：`tools/bake-slate-roof.ps1` 只读取灰瓦纹理；加 `-Gables` 参数才单独生成砖山墙。`tools/build-slate-roof.cjs` 已取消对砖墙瓦片集的依赖；山墙切片由 `tools/build-brick-gables.cjs` 构建。
拆分前备份：`archives/roof-before-separate-gables-20260921.zip`。

试样室内范围对齐：运行时两个图层 gridToPixel(0,0) 都是 (128,64)，但室内地板缩放为 0.25，原范围与当前墙围错位。在现有墙围原点 (0,128)、u跨度6/v跨度5 下，将试样 IndoorFloorLayer 放到 (-32,112)，地板按四分之一墙格覆盖 u=1..23、v=1..19，沿用原地板材质。未改墙格、屋顶瓦片和通用隐藏算法。运行验证 (145.5,761.4) 判为室内隐藏屋顶，(279,819) 判为室外显示屋顶。修改前试样备份于 archives/brick-wall-before-floor-alignment-20260921.ls。后续调整房子形状时，室内地板也需覆盖对应范围。
