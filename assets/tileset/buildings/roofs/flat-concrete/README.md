# 水泥平顶（可双向扩展）

`flat-roof.tres` 为原生等距瓦片集；`flat-roof-layer.lh` 为带 RoofTileLayer 的空屋顶层，节点名 RoofLayer。

## 使用

1. 将 `flat-roof-layer.lh` 放在房屋 House 下，与墙层保持相同位置、缩放；一栋房屋只保留一个名为 RoofLayer 的屋顶层。
2. 中间选图集第一块（00）连续填充，可沿两个等距方向任意扩展。它是平顶，不受旧双坡屋顶 7 格宽度限制。
3. 外沿换成对应收边块。图集 4×4，从左到右、从上到下编号 00–15；只在屋顶外轮廓使用收边，内部相接处用 00。
4. 原有 HouseRoofVisibility 和 RoomRegions 继续控制室内隐藏。平顶不要附带旧 GableLayer（三角山墙）。屋顶瓦片不用于判定室内范围。

| 编号 | 收边方向（按屏幕上的菱形边） |
| --- | --- |
| 00 | 无，中间填充 |
| 01 | 右下 |
| 02 | 左下 |
| 03 | 右下＋左下 |
| 04 | 左上 |
| 05 | 左上＋右下 |
| 06 | 左上＋左下 |
| 07 | 除右上外三边 |
| 08 | 右上 |
| 09 | 右上＋右下 |
| 10 | 右上＋左下 |
| 11 | 除左上外三边 |
| 12 | 左上＋右上 |
| 13 | 除左下外三边 |
| 14 | 除右下外三边 |
| 15 | 四边，独立单格 |

L 形、凹角、天井按每个格子实际露出的边选择组合即可。未设置自动收边，需要手工选择瓦片。扩展指不限制预设屋顶宽高，实际地图大小仍受引擎性能约束。

网格 256×128，单片 320×640，锚点 (160,560)，偏移 (0,-240)，沿用既有屋顶切片和显隐脚本。水泥顶面高 268，板底高 256，与标准墙顶衔接，厚度 12。边界位 +u/+v/-u/-v = 1/2/4/8。材质复用 `../../materials/concrete.png`，固定几何烘焙，不重新生成不一致的轮廓。

制作脚本：`tools/bake-flat-roof.ps1`、`tools/build-flat-roof.cjs`；检查：`tools/test-flat-roof.cjs`。拼接预览：`docs/flat-roof-preview.png`。原双坡屋顶与用户场景不替换。
