# 单格砖墙试样

打开同目录 `brick-wall-sample.ls` 查看实际拼接。运行后用 WASD 或方向键移动；人物从入口进入，墙脚挡路，人物在高墙后会被遮住。

## 在森林里画墙

把 `brick-wall-layer.lh` 拖到森林 `Area2D / ActorLayer` 下，选择它的 TileMapLayer，用内置 `brick-wall.tres` 逐格绘制。保持墙层旋转为0，使用图集中现成的方向块，不要旋转或翻转瓦片。两种直墙在图集第2行第2列、第3行第3列；其余为端头、转角、T形、十字和独立柱。不同连接块需要手动选择，未配置自动地形笔刷。

当前规格：墙模块网格256×128，图片切片256×384，墙体垂直高度256，图片落点(128,336)。纹理偏移Y=-144。模块长度为原来的2倍，墙的实际厚度保持加厚版不变；相对于128×64的森林地面格，每段墙跨两个地面步长，墙层仍逐格绘制。

连接臂优化：半厚改为新模块的3/16，原来的物理厚度不变，中心外的连接臂水平投影由8增加至40像素。16种模块共用统一长度、接口和循环纹理尺度。旧绘制格坐标保留，因网格扩大，已画结构在世界中的跨度相应增加。备份：`archives/brick-wall-before-long-arms-20260921.zip`。

加厚优化：墙体厚度由格宽的1/8增加至1/4，向中心线两侧对称扩展，墙顶、端面、转角和墙脚碰撞同步更新。墙高、切片位置、资源UUID和连接中心保持不变。旧版备份：`archives/brick-wall-before-thickness-20260920.zip`。

2026-09-21：按用户要求在上版厚度基础上再乘3，当前厚度为格宽的3/4（半厚3/8），绘图和碰撞同步。上版备份：`archives/brick-wall-before-triple-20260921.zip`。

宽墙顶使用双轴砖纹映射，避免把原来的一条纹理扫描线拉成条纹；边界仍沿用相同循环相位。

## 制作与验证

内置imagegen生成连续砖纹母图，再用固定2:1投影与统一几何烘焙16种连接形状。不是把之前的装饰墙拼图直接裁开。砖纹沿墙长使用镜像循环，保障切口纹理连续；可能看出重复，不承诺随机纹理变化。完整原提示词位于 `docs/brick-wall-tiles-prompt.txt`。

绘制数据始终保存在真正的TileMapLayer中。运行时 BrickWallTileLayer 将已画单格展开成4像素宽的竖向显示条，与人物在ActorLayer中按脚下深度排序；按同一几何生成墙脚 DepthObstacle，复用正式游戏 TileBlockMovement 碰撞。该方式用于当前小规模试样，墙数量很大时需要做性能优化。适配当前Laya版本的内部chunk表，缺失时会报告错误。

已验证22格围墙全部读取、连续直墙和转角拼接、墙体与转角阻挡、入口允许通过、键盘走进入口及墙前后遮挡。相关TS模块独立类型检查通过。示例人物复用项目Spine外观，用相同移动碰撞类；没有加载完整战斗、背包和摄像机逻辑。

本轮只做砖墙基础连接件，入口通过留空形成；未制作门扇、门洞过梁、窗墙或其他四种材质。未往正式森林地图自动铺墙。所有本轮资源集中在此目录，仅保留这一份可操作示例。

运行时绘制修改后可调用 BrickWallTileLayer.rebuild() 重建。墙层位置/缩放/显隐在初始化时读取，运行期间改变这些属性也需要重建；分类文件夹保持默认变换。

## 碰撞坐标修正（2026-09-21）
运行时发现 Sprite.transform 对等距斜切矩阵的分解会改变碰撞方向：预期第一列 (128,64)，实际读回约 (140.8,-25.6)，导致画面墙体与阻挡轮廓错位。
墙脚节点现只使用位置和普通缩放，DepthObstacle.isometricGround 直接把节点内像素坐标转换为 u=x/256+y/128、v=-x/256+y/128；其余普通装饰物仍使用原矩形坐标。
试样玩家碰撞半宽改为 30，与正式角色的默认半宽一致，可在 BrickWallWalkthrough 属性中调整。测试 tools/test-wall-collision.cjs 覆盖两个方向的门洞、墙面和门柱、非均匀缩放、平移及高速跨越。运行时墙角画面对照已确认消除本次身体嵌墙问题。

碰撞排查补充：对当前试样执行 280 条双向、分步移动路径检查，未出现穿越已登记碰撞块的情况。另修正 DepthObstacle 的重叠脱困漏洞：起点在墙内时仅允许朝最近边界退出，不允许直接穿到另一侧；测试加入同侧退出、对侧穿越以及斜向越界用例。完整运行检查可在试样 BrickWallWalkthrough 的“启动时执行完整碰撞检查”中启用，默认关闭，避免影响平时预览。

贴墙距离修正：人物脚底由只有左右宽度的线段改为椭圆，新增前后半径，默认 20（左右半径仍为 30）。试样在 WalkHere / BrickWallWalkthrough 的“人物脚底碰撞前后半径”调整；正式角色在 PlayerController 的“脚底碰撞前后半径”调整。两条等距墙方向均已运行验证；碰撞测试覆盖前后半径 0/20、双向门洞、缩放和连续移动。此参数控制脚底占地，不按头部或枪械外观扩大碰撞。
贴墙外观复查：旧半宽 30 / 前后半径 20 在 (-53.8,790.5) 仍会削掉人物右侧轮廓。现将试样和正式玩家预制体统一为半宽 48、前后半径 28；该位置向墙靠近停止于约 (-54,803)，人物轮廓完整，另一方向 x=619 停止于 y=649。以上为当前人物尺寸的接触距离调参，碰撞坐标算法不变。前文 30/20 数值为历史记录，以此处为准。
枪管贴墙显示修正：DepthSortable 新增“墙前整体显示半宽（含持枪）”，普通节点默认 0，试样与正式玩家设为 160。角色脚下位于墙面前侧时，在这段显示宽度内越过相关墙条的排序，枪械随角色完整绘制；墙后仍使用脚底排序。处理相邻转角瓦片的面延伸，修复试样 (279,819) 枪口被截断。此项只修正显示，不改变移动碰撞或射击命中规则。验证：tools/test-wall-foreground.cjs；运行画面对比墙前枪管完整、墙后遮挡保留。
室内转角排序回归修正：在 (187.1,741.5) 持续向外移动时坐标被挡住，但相邻墙面的整体显示提升让半个人被画到墙前。foregroundDepth 现在先检查人物脚下前方的实际墙面，存在遮挡时禁止邻接面提升排序。新增该位置回归用例，同时保留 (279,819) 墙外完整持枪显示用例；运行实测室内靠墙不再透出。
玩家墙后可见：DepthSortable 新增“遮挡此人物的墙变半透明”，试样与正式玩家开启，其他节点默认关闭。BrickWallTileLayer 按玩家脚底、身体横向范围及墙高判断实际遮挡，整段瓦片平滑淡至 0.28 不透明度，0.18 秒过渡；离开或停用玩家后恢复。可在墙层组件调整不透明度/过渡秒数。只修改墙面显示节点的 alpha，不改 DepthObstacle、角色位置、屋顶判定。运行验证 (131,769) 遮挡墙透明且碰撞仍阻挡，往室内远离后墙恢复。
视野规则更新：不再以玩家靠墙距离触发透明。由玩家脚底向墙面投影所覆盖的地面采样点检查直线视线，任何砖墙实体占地都会截断射线，门口空格允许视线通过；挡住可见地面的墙段保持半透明。视野为周围全方向，不依赖室内开关，也未限制固定观察半径。玩家 DepthSortable 的“作为玩家视野来源”开启；场景对象的“受玩家墙体视线限制”默认开启，隔墙对象 alpha 为 0，同侧恢复原 alpha，自身豁免。已挂 DepthSortable 的僵尸与装饰自动接入，新场景对象需同样挂组件并设置正确脚底 groundY。砖墙图层每 100ms 更新墙段让视，目标每帧检查。此实现针对 BrickWallTileLayer 实墙；没有为普通草地、地板添加战争迷雾，也未把普通装饰的碰撞自动当作遮光墙。临时添加的两只僵尸验证后已移除，不留新测试场景。验证 test-wall-vision.cjs 和运行时同侧/隔墙目标切换，碰撞回归通过。
屋外误透明回归：玩家 (702.5,833.1) 位于房屋前侧，原规则会因透过入口看到远处地面而让整段外墙变透明。现仅检查当前墙面紧邻背缘的可见性，并要求该墙条脚底深度位于玩家前方。该位置房屋外墙已运行确认恢复实心，室内 (125,448) 前墙仍保持透明；test-wall-vision.cjs 加入两处相反状态及无观察者恢复的回归。独立前景墙仍按自身是否挡住可见地面判断。
房屋内外状态统一：HouseRoofVisibility 将自身室内状态（含门口200ms缓冲）发布到 HouseInteriorState；属于该房屋层级的 BrickWallTileLayer 只有在同一状态为室内时才允许视野透明，室外/玩家缺失/组件禁用时恢复实心。独立墙层没有房屋祖先时沿用地面视线规则。运行复查屋外 (420.8,725.8) 屋顶显示且全部房屋墙段实心；测试覆盖不同房屋隔离、出入切换和墙段揭示开关。
室内三段漏透明修正：玩家在前端 (129,768.2) 时，左入口墙、左侧中段及右入口墙因脚底Y筛选而错误恢复实心。房屋判为室内时取消该Y筛选，仍要求墙背缘地面与玩家视线连通；室外仍由共享室内状态禁止房屋墙透明，独立墙保留前后筛选。三段墙回归、屋外恢复和屋顶测试通过，运行截图确认前侧墙一致半透明。
