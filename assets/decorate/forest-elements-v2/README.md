# 森林独立元素：写实风格版

以 `../forest/` 中的松树、灌木和倒木为美术参考，重绘原 `tileset/forest-kit-v2/elements` 的 24 种元素。使用灰绿、橄榄绿、灰褐木材与自然岩石色，细化枝叶和表面纹理。

这里的独立 PNG 保留真实透明通道，可以分别拖入 LayaAir 场景。文件名与旧版一一对应；此次新增一套供选择，没有自动替换现有场景引用。地块未修改。

元素包括：短草、高草、蕨类、圆灌木、阔叶草、白花；小苔石、三颗卵石、大苔石、扁石、圆石、碎石；树桩、枯枝、树根、倒木、落叶、蘑菇；芦苇、浮叶、浆果灌木、小松树、小阔叶树、枯树苗。

每张画布为 256×256。画布大小不代表统一的世界尺寸：石头、草丛和树木应按场景比例分别缩放。树木与草丛建议按根部落点对齐，岩石按底部落点对齐。

生成使用内置 imagegen，提示词和源图位置见项目根目录 `docs/forest-elements-v2-generation.md`。切片脚本为 `tools/split-forest-props.ps1`，保留 RGBA 像素。
